## 2026-05-20 — Initial APOS Memory Strategy

Decision:

- Use plain files for project memory and coordination.

Reason:

- Human-readable
- AI-readable
- No dependency installation
- No hidden services
- Easy to inspect and modify

Impact:

- Synchronization becomes explicit
- Long-term context remains portable
- Memory remains transparent

Alternatives considered:

- Database-backed memory
- Autonomous agent memory systems
- Hidden background synchronization

Result:

- Rejected in favor of simple file-based persistence
