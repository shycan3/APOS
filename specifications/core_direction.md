# Core Direction

## Project Objective

Build a lightweight AI collaboration runtime
that preserves long-term project context across
multiple AI systems.

Examples:

- ChatGPT
- Codex
- Gemini

Primary goals:

- reduce context drift
- reduce repeated explanations
- preserve decision history
- maintain traceability

--------------------------------------------------

## Long-term Vision

Create a collaboration structure that:

- humans can understand
- AI systems can navigate
- remains lightweight
- remains inspectable
- avoids hidden complexity

--------------------------------------------------

## Non-goals

APOS should not become:

- autonomous agent framework
- hidden automation platform
- database-driven memory system
- unnecessarily complex infrastructure
